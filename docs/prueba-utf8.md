# Archivo de Prueba UTF-8

Este archivo contiene caracteres especiales para verificar que el sistema maneja correctamente UTF-8.

Caracteres acentuados: **áéíóúñÑ**

Símbolos: **¿¡ €**

Oración de ejemplo: La Clínica del Hospital de Córdoba atiende pacientes con síntomas de hipertensiónm y Diabetes.

## Verificación

Si este archivo se abre correctamente en cualquier editor sin caracteres rotos, la auditoría de UTF-8 pasó exitosamente.
